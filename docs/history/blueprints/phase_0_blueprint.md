# FormaTavern — Phase 0 Blueprint: The Walking Skeleton

**Purpose:** Prove, end-to-end, that one Bun workspace can (a) resolve a shared TypeScript package from both server and browser, (b) run Elysia and the SvelteKit/Vite dev server side-by-side with `/api` proxied, (c) push an SSE token stream through that proxy *without buffering*, and (d) collapse to a single Bun process serving the built SPA in production.

Nothing else. If a task isn't required to prove one of those four things, it is out of scope (see §5.3).

**Toolchain baseline:** Bun ≥ 1.2 (text `bun.lock`, stable `--filter`), Elysia 1.x, SvelteKit 2 + Svelte 5, Vite 6+, TypeScript 5.5+. Pin `@elysiajs/eden` and `@elysiajs/static` to the same major/minor line as `elysia`.

## 1. Monorepo Topology & Package Boundaries

### 1.1 Directory layout

```
formatavern/
├── package.json                 # workspace root (private)
├── bun.lock
├── tsconfig.base.json           # shared strict defaults (extended by each package)
├── .gitignore                   # node_modules, frontend/build, frontend/.svelte-kit, *.db
│
├── backend/                     # @formatavern/backend
│   ├── package.json
│   ├── tsconfig.json
│   └── src/
│       ├── app.ts               # Pure Elysia app: routes only. NO Bun globals. Exports `type App`.
│       └── index.ts             # Process entry: env, security warning, prod static serving, listen()
│
├── frontend/                    # @formatavern/frontend
│   ├── package.json
│   ├── svelte.config.js         # adapter-static, SPA fallback
│   ├── vite.config.ts           # /api proxy + SSE safeguards
│   ├── tsconfig.json            # generated by sv; do not hand-edit paths
│   └── src/
│       ├── app.html
│       ├── app.d.ts
│       ├── lib/api.ts           # Eden treaty client (health) + raw SSE reader (stream)

│           └── +page.svelte     # bare canvas: button + <pre>
│
└── packages/
    └── shared/                  # @formatavern/shared

        └── src/index.ts
```

### 1.2 Workspace responsibilities and the dependency graph

```
              runtime + types           types ONLY (import type)
  frontend ─────────────────► shared ◄──────────────── backend
      ▲                                                   │
      └──────────── import type { App } ──────────────────┘
      (backend reads frontend/build/ from disk in prod — never imports it)
```

| Package | Owns | May import | Must never import |
|---|---|---|---|
| `packages/shared` | Wire-level contracts: types, constants, (later) TypeBox schemas and the envelope parser. Zero runtime deps in Phase 0. | Nothing (Phase 0) | `bun:*`, `node:*`, DOM (`window`, `document`), `elysia`, `svelte` |
| `backend` | Elysia app, process bootstrap, prod static serving | `@formatavern/shared`, `elysia`, `@elysiajs/static`, `bun:*`, `node:*` | Anything from `frontend/src` |
| `frontend` | SvelteKit SPA, Vite proxy config | `@formatavern/shared` (runtime), `@formatavern/backend` (**type-only**), `@elysiajs/eden` | Backend *values* (would drag Elysia into the browser bundle) |

**Isomorphism rule for `shared`:** anything in `shared` must execute identically in Bun and in a browser. The `shared/tsconfig.json` enforces this mechanically (`lib: ["ES2022"]`, `types: []`) — referencing `window` or `Bun` there is a type error.

**Purity rule for `backend/src/app.ts`:** the file whose type the frontend imports must contain no `Bun.*` globals and no `bun:*` imports. All Bun-specific code (`Bun.file`, `import.meta.dir`, `listen`) lives in `index.ts`. Reason: `svelte-check` type-checks every file reachable through `import type`, under the frontend's compiler options.

### 1.5 TypeScript configuration contract

`tsconfig.base.json` (root):
```json
{
  "compilerOptions": {
    "strict": true, "target": "ES2022", "module": "ESNext",
    "moduleResolution": "bundler", "verbatimModuleSyntax": true,
    "isolatedModules": true, "skipLibCheck": true, "noEmit": true,
    "allowImportingTsExtensions": true
  }
}
```
- `shared/tsconfig.json`: extends base; `"lib": ["ES2022"]`, `"types": []`, `"include": ["src"]`.
- `backend/tsconfig.json`: extends base; `"lib": ["ESNext"]`, `"types": ["bun"]`, `"include": ["src"]`.
- `frontend/tsconfig.json`: leave as generated by `sv` (it extends `.svelte-kit/tsconfig.json`, already `moduleResolution: "bundler"`). **Do not add `paths`** — SvelteKit overwrites/warns; if aliasing is ever needed, use `kit.alias` in `svelte.config.js`.

`moduleResolution: "bundler"` is what makes `exports` → `./src/index.ts` resolve in the type system on all three sides. Bun's runtime and Vite's resolver both honor `exports` and load `.ts` natively, so no build step exists for `shared` in Phase 0.

## 2. Integration & Proxy Architecture

### 2.1 Development topology

```
Browser ──► Vite dev server  http://localhost:5173
              ├── /api/*  ──proxy──►  Elysia  http://127.0.0.1:3000  (bound to 127.0.0.1)
              └── everything else → SvelteKit routes + HMR
```

Same-origin from the browser's perspective; no CORS anywhere (ADR-004). All frontend fetches use relative paths (`/api/...`).

**`frontend/vite.config.ts`:**
```ts
import { sveltekit } from '@sveltejs/kit/vite';
import { defineConfig, searchForWorkspaceRoot } from 'vite';

export default defineConfig({
  plugins: [sveltekit()],
  server: {
    port: 5173,
    strictPort: true,
    fs: { allow: [searchForWorkspaceRoot(process.cwd())] }, // serve ../packages/shared/src (symlink resolves outside frontend/)
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:3000',   // IPv4 literal. NOT "localhost". See §4.3
        changeOrigin: true,
        ws: false,
        // http-proxy pipes chunked responses without buffering by default.
        // The hooks below are defensive: forbid compression negotiation and
        // pin no-cache/no-transform semantics on event streams.
        configure(proxy) {
          proxy.on('proxyReq', (proxyReq) => {
            proxyReq.setHeader('Accept-Encoding', 'identity');
          });
          proxy.on('proxyRes', (proxyRes, _req, res) => {
            const ct = proxyRes.headers['content-type'] ?? '';
            if (ct.startsWith('text/event-stream')) {
              res.setHeader('Cache-Control', 'no-cache, no-transform');
              res.setHeader('X-Accel-Buffering', 'no');
              res.flushHeaders?.();
            }
          });
        }
      }
    }
  }
});
```

Rules that keep this honest:
- **Never** set `proxyTimeout` / `timeout` on the `/api` proxy entry; long-lived streams must not be reaped.
- **Never** create `frontend/src/routes/api/…` — it would shadow-collide with the proxied namespace (the proxy middleware runs first, but the ambiguity is a maintenance trap).
- The server response itself must have `Content-Type: text/event-stream`, no `Content-Length`, and be produced by a `ReadableStream` (chunked). The proxy cannot un-buffer a response the server assembled whole.

**`frontend/svelte.config.js`:**
```js
import adapter from '@sveltejs/adapter-static';
import { vitePreprocess } from '@sveltejs/vite-plugin-svelte';
export default {
  preprocess: vitePreprocess(),
  kit: { adapter: adapter({ pages: 'build', assets: 'build', fallback: 'index.html', precompress: false }) }
};
```
**`frontend/src/routes/+layout.ts`:** `export const ssr = false;` (pure SPA; `prerender` stays default `false`, satisfied by `fallback`).

### 2.2 Production topology contract

```
Browser ──► Bun process (Elysia)  http://127.0.0.1:3000
              ├── /api/*                 → API routes (JSON / SSE)
              ├── /<existing file>       → served from frontend/build/ (immutable hashed assets)
              └── /<anything else>       → frontend/build/index.html (SPA fallback, HTTP 200)
              /api/<unknown>             → 404 (JSON), NEVER index.html
```

Contract points:
1. `bun run build` produces `frontend/build/` (SvelteKit + adapter-static). `bun run start` runs `backend/src/index.ts` with `NODE_ENV=production`.
2. Build dir is resolved **relative to the backend source file**, not `cwd`: `join(import.meta.dir, '../../frontend/build')`. Startup fails loudly if it doesn't exist in production mode.
3. Route precedence: `/api/*` registered before the static plugin; the SPA fallback lives in `onError` for `NOT_FOUND` and explicitly excludes paths starting with `/api/`.
4. Dev-only concerns (proxy) live in `vite.config.ts` only; prod-only concerns (static) live in `index.ts` gated by `NODE_ENV`. `app.ts` knows about neither.

`backend/src/index.ts` (shape):
```ts
import { Elysia } from 'elysia';
import { staticPlugin } from '@elysiajs/static';
import { existsSync } from 'node:fs';
import { join } from 'node:path';
import { app } from './app';

const HOST = process.env.FORMATAVERN_HOST ?? '127.0.0.1';
const PORT = Number(process.env.FORMATAVERN_PORT ?? 3000);
const PROD = process.env.NODE_ENV === 'production';
const BUILD_DIR = join(import.meta.dir, '../../frontend/build');

if (HOST === '0.0.0.0') console.warn(`[SECURITY WARNING] ...`); // exact text from ADR-006 §1

const server = new Elysia().use(app);

if (PROD) {
  if (!existsSync(BUILD_DIR)) throw new Error(`Production build missing: ${BUILD_DIR}. Run 'bun run build'.`);
  server
    .use(staticPlugin({ assets: BUILD_DIR, prefix: '/', indexHTML: true }))
    .onError(({ code, request, set }) => {
      if (code === 'NOT_FOUND' && !new URL(request.url).pathname.startsWith('/api/')) {
        set.status = 200;
        return Bun.file(join(BUILD_DIR, 'index.html'));
      }
    });
}

server.listen({ hostname: HOST, port: PORT });
console.log(`[formatavern] ${PROD ? 'prod' : 'dev'} backend → http://${HOST}:${PORT}`);
```
If `@elysiajs/static`'s option surface has drifted in the pinned version, replace it with a `get('/*')` handler that resolves `join(BUILD_DIR, pathname)`, rejects any resolved path not inside `BUILD_DIR` (traversal guard), serves `Bun.file` if it exists, else `index.html`. Same contract either way.

## 3. Core Contracts & Endpoints (Phase 0 Scope)

### 3.1 `@formatavern/shared` — the minimal contract

`packages/shared/src/index.ts`:
```ts
export const SHARED_VERSION = '0.0.1-phase0';

/** Subset of the Phase 2 StreamEvent union — names/shapes chosen so nothing renames later. */
export type StreamEvent =
  | { type: 'token'; text: string }
  | { type: 'done'; finishReason: 'stop' | 'aborted' };

export interface HealthResponse {
  ok: true;
  service: 'formatavern-backend';
  sharedVersion: string;     // echoes SHARED_VERSION → proves backend resolved the workspace
  timestamp: number;         // Unix ms
}

export const TEST_STREAM_WORDS = ['Forma', 'Tavern', 'walking', 'skeleton', 'online'] as const;
export const TEST_STREAM_INTERVAL_MS = 400;
export const TEST_STREAM_EXPECTED_TEXT = TEST_STREAM_WORDS.join(' ');
```
Why constants and not just types: types are erased. The backend *emitting* `TEST_STREAM_WORDS` and the frontend *asserting* against `TEST_STREAM_EXPECTED_TEXT` proves runtime resolution of the symlinked package on both sides, not merely type resolution.

### 3.2 Elysia server interface (`backend/src/app.ts`)

```ts
import { Elysia } from 'elysia';
import {
  SHARED_VERSION, TEST_STREAM_WORDS, TEST_STREAM_INTERVAL_MS,
  type HealthResponse, type StreamEvent
} from '@formatavern/shared';

const sleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms)); // no Bun.sleep here (purity rule)

export const app = new Elysia({ prefix: '/api' })
  .get('/health', (): HealthResponse => ({
    ok: true, service: 'formatavern-backend', sharedVersion: SHARED_VERSION, timestamp: Date.now()
  }))
  .post('/chat/test-stream', ({ request }) => {
    const encoder = new TextEncoder();
    let cancelled = false;
    const frame = (e: StreamEvent) => encoder.encode(`data: ${JSON.stringify(e)}\n\n`);

    const body = new ReadableStream<Uint8Array>({
      async start(controller) {
        for (let i = 0; i < TEST_STREAM_WORDS.length; i++) {
          if (cancelled || request.signal.aborted) return;
          controller.enqueue(frame({ type: 'token', text: (i === 0 ? '' : ' ') + TEST_STREAM_WORDS[i] }));
          if (i < TEST_STREAM_WORDS.length - 1) await sleep(TEST_STREAM_INTERVAL_MS);
        }
        if (!cancelled) {
          controller.enqueue(frame({ type: 'done', finishReason: 'stop' }));
          controller.close();
        }
      },
      cancel() { cancelled = true; console.log('[test-stream] client disconnected'); }
    });

    return new Response(body, {
      headers: {
        'Content-Type': 'text/event-stream; charset=utf-8',
        'Cache-Control': 'no-cache, no-transform',
        'Connection': 'keep-alive',
        'X-Accel-Buffering': 'no'
      }
    });
  });

export type App = typeof app;
```

**Endpoint contracts:**

| Endpoint | Request | Response |
|---|---|---|
| `GET /api/health` | none | `200`, `application/json`, body = `HealthResponse` |
| `POST /api/chat/test-stream` | **no body, no Content-Type** | `200`, `text/event-stream; charset=utf-8`, `Transfer-Encoding: chunked`, no `Content-Length`. Exactly 6 frames: 5 `token` (~400 ms apart, tokens 2–5 carry a leading space, like real LLM tokens) then 1 `done`. Connection closes after `done`. |

**Wire format (normative):** each frame is `data: <JSON StreamEvent>\n\n`. No `event:`/`id:` lines emitted. Clients must nonetheless ignore any non-`data:` lines (forward compatibility with Elysia's `sse()` helper, which may add `id:`).

The hand-built `Response(ReadableStream)` is chosen as normative because it is byte-exact and version-agnostic across Elysia 1.x. Elysia's generator + `sse()` sugar is a Phase 3 candidate; if the agent swaps it in, it must re-run the curl byte checks in §5.2 and confirm identical framing. Dropping the framework's sugar is acceptable; deviating from the wire contract is not.

### 3.3 Frontend consumer contract

Two verification paths, deliberately different:
- **Health via Eden Treaty** → proves cross-workspace *type* sharing (`import type { App }`) and same-origin routing.
- **Stream via raw `fetch` + `ReadableStream`** → proves *bytes* arrive incrementally. Eden's streaming ergonomics are not under test in Phase 0.

**Precision note on `TextDecoder`:** the `{ stream: true }` option belongs on `decode()`, not the constructor. `new TextDecoder('utf-8').decode(chunk, { stream: true })` retains partial multi-byte sequences across chunk boundaries; call `decoder.decode()` with no args once at the end to flush. The constructor only accepts `{ fatal, ignoreBOM }`.

`frontend/src/lib/api.ts`:
```ts
import { treaty } from '@elysiajs/eden';
import type { App } from '@formatavern/backend';          // type-only — never a value import
import type { StreamEvent } from '@formatavern/shared';

export const api = treaty<App>(window.location.origin);   // relative origin per ADR-004; SPA-only so window exists

export interface StreamCallbacks {
  onEvent(e: StreamEvent): void;
  onChunk?(bytes: number, deltaMs: number): void;          // raw arrival telemetry (buffering detector)
}

export async function readTestStream(cb: StreamCallbacks, signal?: AbortSignal) {
  const res = await fetch('/api/chat/test-stream', { method: 'POST', signal });  // no body, no headers
  if (!res.ok || !res.body) throw new Error(`stream failed: ${res.status}`);

  const reader = res.body.getReader();
  const decoder = new TextDecoder('utf-8');
  let buf = '';
  let last = performance.now();

  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    const now = performance.now();
    cb.onChunk?.(value.byteLength, Math.round(now - last));
    last = now;

    buf += decoder.decode(value, { stream: true });
    let sep: number;
    while ((sep = buf.indexOf('\n\n')) !== -1) {
      const frameText = buf.slice(0, sep);
      buf = buf.slice(sep + 2);
      const data = frameText.split('\n')
        .filter((l) => l.startsWith('data:'))
        .map((l) => l.slice(5).trimStart())
        .join('\n');
      if (data) cb.onEvent(JSON.parse(data) as StreamEvent);
    }
  }
  buf += decoder.decode(); // flush
}
```

`frontend/src/routes/+page.svelte` (Svelte 5 runes; bare canvas — no styling):
```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  import { TEST_STREAM_EXPECTED_TEXT } from '@formatavern/shared';
  import { api, readTestStream } from '$lib/api';

  let health = $state('…');
  let text = $state('');
  let status = $state<'idle' | 'streaming' | 'done' | 'error'>('idle');
  let deltas = $state<number[]>([]);

  onMount(async () => {
    const { data, error } = await api.api.health.get();
    health = error ? `ERROR ${error.status}` : `ok · shared ${data.sharedVersion}`;
  });

  async function run() {
    text = ''; deltas = []; status = 'streaming';
    try {
      await readTestStream({
        onEvent: (e) => { if (e.type === 'token') text += e.text; else status = 'done'; },
        onChunk: (_b, d) => { deltas.push(d); }
      });
      if (status !== 'done') status = 'error';
    } catch { status = 'error'; }
  }
</script>

<p>health: {health}</p>
<button onclick={run} disabled={status === 'streaming'}>Run test stream</button>
<pre>{text}</pre>
<p>status: {status} {status === 'done' && text === TEST_STREAM_EXPECTED_TEXT ? '✓ matches shared contract' : ''}</p>
<p>chunk deltas (ms): {deltas.join(', ')}</p>
```
Rendering is unbuffered by construction: `text` mutates per event and Svelte flushes to the `<pre>` on the next microtask. The `deltas` readout is the buffering oracle — see §5.1.

## 4. Tricky Traps & Failure Modes

### 4.1 Bun workspaces & TypeScript resolution

| Trap | Symptom | Guard |
|---|---|---|
| `bun install` run inside a sub-package | Partial/duplicated `node_modules`, missing workspace symlinks | Always `bun install` from the repo root. Verify `ls -la node_modules/@formatavern/` shows symlinks (junctions on Windows) to `../../packages/shared` and `../../backend`. |
| Frontend `svelte-check` reports errors *inside* `backend/src/index.ts` | `Cannot find name 'Bun'` | `import type { App }` only from `app.ts`, which is Bun-global-free (purity rule §1.2). |
| Root-hoisted `@types/bun` auto-included by the frontend program | Usually silent; occasionally masks the purity violation above | Accept as benign, but don't rely on it — purity rule stands regardless. |
| Value import of backend in frontend | Vite tries to bundle Elysia for the browser; obscure resolution errors | `verbatimModuleSyntax: true` + lint discipline: `import type` only. |
| `exports` → `.ts` not resolving in TS | `Cannot find module '@formatavern/shared'` while Bun runs fine | Confirm `moduleResolution: "bundler"` in every package. Last-resort fallback: `kit.alias` in `svelte.config.js` (frontend) / `paths` in `backend/tsconfig.json` pointing to `../packages/shared/src/index.ts`. |
| Vite "outside of allow list" error for `packages/shared/src/index.ts` | 403 on the module in the browser console | `server.fs.allow: [searchForWorkspaceRoot(...)]` (already in §2.1). |
| Shared package quietly uses `window` or `Bun` | Works on one side, crashes on the other | `shared/tsconfig.json` with `lib: ["ES2022"]`, `types: []` turns this into a compile error. |
| `bun --watch` + `bun.lock` churn | Watch restarts on install | Cosmetic; stop dev servers before `bun add`. |

### 4.2 SSE through the Vite proxy

| Trap | Symptom | Guard |
|---|---|---|
| Server builds the whole body in memory | All frames arrive in one burst; deltas ≈ 0 ms | Must return `Response(new ReadableStream(...))`, no `Content-Length`. |
| Compression somewhere in the chain | Stalled stream until close | Vite dev has no compression; `Accept-Encoding: identity` on proxyReq is belt-and-braces. Never add a compression middleware in front of `/api`. |
| Proxy `timeout`/`proxyTimeout` set | Long generations drop mid-stream | Do not set them. |
| Client sends `Content-Type: application/json` with empty body | Elysia body parsing may reject (400/422) | Send no body and no Content-Type for this endpoint. |
| Frame parsing on `\n` instead of `\n\n` | Truncated/garbled JSON | Frame on the blank-line separator; then filter `data:` lines. Our server emits LF only; a CRLF-tolerant parser (`\r?\n`) is acceptable but not required in Phase 0. |
| Client disconnect leaves a zombie loop server-side | Log spam after Ctrl+C in curl | `cancel()` sets `cancelled`; Bun also aborts `request.signal`. Verified in §5.2 step 6. |
| PowerShell `curl` alias | `Invoke-WebRequest` buffers the whole response; "no streaming" false alarm | Use `curl.exe -N`. |

### 4.3 OS-specific nuances

- **`localhost` vs `127.0.0.1` (all OSes, worst on Windows/macOS):** Node (which runs Vite) may resolve `localhost` to `::1` first. Elysia is bound to `127.0.0.1` per ADR-006 (`Bun.serve` with an IPv4 hostname listens IPv4 only) → proxy gets `ECONNREFUSED`. Proxy target is therefore the literal `http://127.0.0.1:3000`. Use `127.0.0.1` in all curl checks too. In the browser, use whichever URL Vite prints.
- **Windows file locking:** `EBUSY`/`EPERM` when running `bun run clean` or `bun install` while `bun --watch` or Vite has files/handles open. Stop both servers first. Deleting `frontend/.svelte-kit` while `vite dev` runs corrupts the dev session — restart it.
- **Windows firewall prompt:** binding to `127.0.0.1` avoids the Defender dialog; `0.0.0.0` triggers it (and the ADR-006 warning).
- **Windows path joins:** always `node:path` `join`/`resolve`; never string-concatenate `/`.
- **Port collisions on fast restart:** `bun --watch` rebinds cleanly on Linux/macOS; on Windows an occasional `EADDRINUSE` on rapid double-save resolves on the next save. `strictPort: true` on Vite fails fast rather than silently moving to 5174 (which would break nothing but confuse verification).

## 5. Definition of Done & Verification Checklist

### 5.1 Acceptance criteria (all must hold)

1. **Install:** `bun install` from root completes; `node_modules/@formatavern/{shared,backend,frontend}` are workspace links.
2. **Types:** `bun run typecheck` passes in all three packages with zero errors (including `svelte-check` traversing `import type { App }`).
3. **Health, direct:** `GET 127.0.0.1:3000/api/health` returns `HealthResponse` with `sharedVersion === "0.0.1-phase0"`.
4. **Health, proxied:** the same via `127.0.0.1:5173/api/health` returns an identical body.
5. **Stream, direct:** `POST /api/chat/test-stream` on :3000 returns `text/event-stream`, chunked, exactly 5 `token` frames + 1 `done`, visibly paced (~400 ms).
6. **Stream, proxied:** identical behavior through :5173. **Pacing proof:** the frontend's `deltas` readout shows ≥ 4 inter-chunk gaps in the 250–600 ms range. A single burst (all gaps < 50 ms) is a **FAIL** (buffering).
7. **Browser:** clicking *Run test stream* appends words to `<pre>` one at a time; final text equals `Forma Tavern walking skeleton online`; page shows `✓ matches shared contract`; health line shows `ok · shared 0.0.1-phase0`.
8. **Disconnect hygiene:** aborting a client mid-stream logs `[test-stream] client disconnected` once and the server keeps serving subsequent requests.
9. **Production:** `bun run build && bun run start` → `GET /` serves the SPA, `GET /any/deep/path` returns `index.html` (200), `GET /api/health` still JSON, `GET /api/does-not-exist` is 404 (not `index.html`), and the stream test passes in the browser at `127.0.0.1:3000` with no proxy involved.
10. **Security posture:** starting with `FORMATAVERN_HOST=0.0.0.0` prints the ADR-006 warning; default start does not.

### 5.2 Step-by-step verification

```bash
# 0. Clean slate
bun --version                       # ≥ 1.2
bun install
ls -la node_modules/@formatavern/   # expect 3 symlinks/junctions
bun run typecheck

# 1. Start both servers (one terminal, prefixed output)
bun run dev
#   expect: "[formatavern] dev backend → http://127.0.0.1:3000" and Vite on :5173

# 2. Health — direct and proxied (separate terminal)
curl -si http://127.0.0.1:3000/api/health
curl -si http://127.0.0.1:5173/api/health
#   both: HTTP 200, content-type application/json, "sharedVersion":"0.0.1-phase0"

# 3. Stream headers — must be event-stream + chunked, must NOT have content-length
curl -sI -X POST http://127.0.0.1:3000/api/chat/test-stream | tr -d '\r'   # or use -D - -o /dev/null

# 4. Stream body with wall-clock timestamps — direct, then proxied
curl -sN -X POST http://127.0.0.1:3000/api/chat/test-stream \
  | while IFS= read -r line; do printf '%s  %s\n' "$(date +%T.%3N)" "$line"; done
curl -sN -X POST http://127.0.0.1:5173/api/chat/test-stream \
  | while IFS= read -r line; do printf '%s  %s\n' "$(date +%T.%3N)" "$line"; done
#   expect 6 "data:" lines; timestamps step ~0.4 s; total ≈ 1.6 s. Burst = FAIL.
#   Windows: use curl.exe -N (PowerShell's curl alias buffers).

# 5. Browser
#   open the URL Vite printed → health line "ok · shared 0.0.1-phase0"
#   click "Run test stream" → words appear incrementally → "✓ matches shared contract"
#   DevTools ▸ Network ▸ test-stream ▸ EventStream tab lists 6 messages arriving over time
#   chunk deltas line: e.g. "12, 401, 399, 402, 400, 3"

# 6. Disconnect hygiene
curl -sN -X POST http://127.0.0.1:5173/api/chat/test-stream & sleep 0.6; kill %1
#   backend log: "[test-stream] client disconnected" (once); then step 2 still passes

# 7. Production single-process
#   stop `bun run dev` first (Windows: avoids EBUSY on build/)
bun run build                         # → frontend/build/index.html exists
bun run start
curl -si http://127.0.0.1:3000/              | head -5     # 200 text/html
curl -si http://127.0.0.1:3000/chat/abc123   | head -5     # 200 text/html (SPA fallback)
curl -si http://127.0.0.1:3000/api/health    | head -5     # 200 application/json
curl -si http://127.0.0.1:3000/api/nope      | head -5     # 404, NOT html
#   browser at http://127.0.0.1:3000 → repeat step 5

# 8. Security warning
FORMATAVERN_HOST=0.0.0.0 bun run start        # expect [SECURITY WARNING] block; Ctrl+C
```

### 5.3 Explicit scope boundaries — deferred to Phase 1+

Do **not** introduce any of the following in Phase 0, even as stubs:

- **Persistence:** no `bun:sqlite`, no `formatavern.db`, no migration runner, no `PRAGMA` setup, no `/data/assets`.
- **Schemas:** no TypeBox, no `CharacterCard`/`CharacterTheme`/`Segment` types, no validation at boundaries.
- **LLM engine:** no `LLMProvider` interface, no `MockLLMProvider`, no OpenRouter adapter, no `jsonrepair`, no envelope parser. The timed word stream *is* the Phase 0 mock.
- **Prompting:** no `PromptBuilder`, no macros, no `gpt-tokenizer`.
- **API surface:** no `/api/chat/send`, `/stop`, `/regenerate`, `/continue`, no `messageId` protocol, no `AbortController` map. (Disconnect handling in §3.2 is passive hygiene, not the abort feature.)
- **Frontend:** no Tailwind, no theme tokens or CSS variables, no `/chat/[chatId]` route, no `<MessageTurn />`, no markdown/DOMPurify, no `BroadcastChannel`, no virtualized list. The page stays an unstyled `<button>` + `<pre>`.
- **Infra:** no auth gate, no `FORMATAVERN_PASSWORD`, no Tailscale/Cloudflare docs, no `bun build --compile` single binary.

What Phase 0 hands to Phase 1 is a proven pipe and three settled conventions: source-exported `shared`, the `app.ts`/`index.ts` purity split, and the `data: <StreamEvent>\n\n` wire contract.

## 6. Execution Order (for the agent)

1. Root `package.json`, `tsconfig.base.json`, `.gitignore`.
2. `packages/shared` (manifest, tsconfig, `src/index.ts`).
3. `backend` (manifest, tsconfig, `app.ts`, `index.ts`). `bun install`, then verify §5.2 steps 2–4 **directly on :3000** before touching the frontend — isolates server-side stream faults from proxy faults.
4. Scaffold `frontend` with `sv create … --no-install`; rename package; swap to adapter-static; add deps; write `vite.config.ts`, `+layout.ts`, `lib/api.ts`, `+page.svelte`. `bun install` from root again.
5. `bun run typecheck` — fix resolution issues here, not later.
6. `bun run dev`; complete §5.2 steps 2–6 through the proxy.
7. Production pass (§5.2 steps 7–8).
8. Record the observed chunk deltas and curl timestamp output in the PR description as the artifact of acceptance criterion 6.
